# 2MD55.ARCH — Changelog Asset Pack / 0401

Дополнение к основному набору ассетов сайта. Все пути в CSS относительны к папке пакета.

## Главное
- `backgrounds/changelog-desktop.webp` — новый фон 1536×1024, без текста и UI. PNG — исходник без потерь; WebP — для сайта.
- `backgrounds/right-room-mobile.webp` — вертикальная вырезка правой части фона. Это не отдельная перерисовка мобильного экрана.
- `backgrounds/*-overlay.png` — фрагменты фона с плавными прозрачными краями для адаптивной композиции.
- `characters/teto-desk-right.png` — прозрачная вырезка Teto вместе с кружкой и книгами; правая и нижняя части обрезаны как на исходной иллюстрации.
- `mascot/sleeping-cat.png` — отдельная вырезка спящего кота; `decor/zzz.svg` можно анимировать отдельно.
- `ui/` — чистые бумажные плашки, рамки и бейджи версий без надписей.
- `icons/` — SVG иконки проектов, навигации и типов изменений. Новые иконки используют `currentColor`; при использовании через `<img>` цвет по умолчанию чёрный. Для управления цветом используйте inline SVG или CSS mask (пример в `changelog.css`).
- `decor/` — узел и линия таймлайна, четыре варианта декоративного угла, фирменные штрихи и спираль.
- `branding/changelog-title-reference.png` — надпись из исходного макета, только для визуального референса; для доступности лучше сверстать заголовок текстом.
- `references/changelog-desktop-original.png` — исходный макет Changelog. Даты, версии и тексты в нём демонстрационные, не реальные данные проекта.

## Подключение
```html
<link rel="stylesheet" href="changelog.css">
<main class="cl-page">
  <h1 class="cl-heading">CHANGELOG</h1>
  <ol class="cl-timeline">
    <li class="cl-release">
      <header class="cl-release-header">
        <span class="cl-version">vX.Y.Z</span>
        <strong>TZAR-HUB</strong>
        <time>YYYY-MM-DD</time>
      </header>
      <p><span class="cl-icon cl-added" aria-hidden="true"></span> Added: ...</p>
    </li>
  </ol>
</main>
```

Это ассеты и стартовые стили, не готовая страница. Фон и персонаж воссозданы генерацией по макету, PNG-вырезки имеют ручную контурную маску, а некоторые общие элементы переиспользованы из первого пакета. Шрифты не включены. Для новых элементов сохранена исходная ограниченная палитра (вместо зелёного для Added используется красный; текстовое обозначение остаётся). Графика с Kasane Teto — фан-арт, не официальный брендовый арт; при публичном использовании проверьте актуальные условия правообладателя.
